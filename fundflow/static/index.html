FundFlow / iShare Reports View source

From fund reports to validated holdings

I built FundFlow to automate a recurring operations task: collect a fund’s holdings report, check its contents, and make the results available for review.

Using real iShares reports, the pipeline preserves original CSV files in an AWS S3 bucket, validates their contents, and stores accepted holdings in MongoDB Atlas with a link to their source. Explore the reports and processing history below.

Built with Python · Playwright · AWS S3 · MongoDB Atlas · FastAPI · pytest · Vercel
